# Стоп-ставка

Веб-приложение, которое помогает бросить ставки на спорт и онлайн-казино. Аудитория — молодёжь от 16 до 40 лет в Кыргызстане и Казахстане. Устанавливается на экран телефона как обычное приложение, работает без регистрации, личные данные хранятся только на устройстве пользователя.

Языки: русский (полностью), кыргызский и казахский (основные экраны; остальное пока показывается по-русски). Валюты: сом и тенге.

## Что внутри

| Экран | Что делает |
|---|---|
| Тест | Международная шкала PGSI (9 вопросов, 0–27 баллов) и честный результат без диагноза |
| План | Дата последней ставки, траты в неделю, личные причины, цель, близкий человек |
| Главная | Дни без ставок, сохранённые деньги, прогресс цели, кнопка «Тянет поставить» |
| SOS | 10-минутный таймер с дыханием, личные причины, кнопка «Написать» близкому в WhatsApp, итог и триггер |
| Дневник | Отметка дня (настроение, тяга, триггеры, ставка) и графики: тяга по дням, частые триггеры, время суток |
| Защита | 8 шагов блокировки: фильтр сайтов (NextDNS), «Экранное время» на iPhone, ограничения Google Play, лимиты в банке, самоограничение через eGov (Казахстан) |
| Правда о ставках | Калькулятор маржи букмекера, ожидаемый проигрыш за год, шанс оказаться в плюсе, симуляция года и кнопка «Поделиться» |
| Помощь | Экстренные номера, куда обратиться, группы взаимопомощи, советы близким |
| ИИ-поддержка | Чат с Claude в момент тяги; кризисные сообщения сразу показывают экстренные номера |
| Плюс | Подписка: ИИ без дневного лимита и статистика за 90 дней; оплата переводом, активация кодом |

## Запуск на компьютере

Нужен Node.js 22.5 или новее.

```bash
cd stopstavka
npm install
AI_MOCK=1 npm start     # ИИ в тестовом режиме, ключ не нужен
# откройте http://localhost:8080
```

С настоящим ИИ: скопируйте `.env.example` в `.env`, заполните `ANTHROPIC_API_KEY` и `APP_SECRET`, запустите `npm start`.

## Выкладка

Приложению нужен один процесс Node и папка для базы (`DATA_DIR`). Подойдёт любой хостинг с Docker и постоянным диском: Railway, Fly.io, Render (платный тариф с диском) или VPS.

```bash
docker build -t stopstavka .
docker run -p 8080:8080 -v stopstavka-data:/data \
  -e APP_SECRET=... -e ANTHROPIC_API_KEY=... -e TRUST_PROXY=1 stopstavka
```

Для установки на телефон нужен HTTPS: платформы выше дают его сами, на VPS поставьте nginx с Let's Encrypt. Все переменные описаны в `.env.example`.

## Как устроены данные

- Всё, что вводит человек (план, дневник, SOS, переписка с ИИ), хранится в `localStorage` его телефона. Есть экспорт в файл и полное удаление.
- Сервер хранит только хеши кодов подписки, счётчики сообщений ИИ по обезличенному хешу устройства и дневные счётчики событий без привязки к людям.
- Сообщения чата уходят в Anthropic (США) только на время ответа — об этом сказано в чате. Закон Казахстана о персональных данных требует согласия на передачу за границу: перед запуском в Казахстане добавьте согласие в пользовательское соглашение.
- Закон Казахстана «Об ИИ» требует предупреждать, что отвечает ИИ, и маркировать сгенерированное: в чате есть пометка «Вы говорите с ИИ» и подпись раздела «ИИ-поддержка».

## ИИ-поддержка

- Модель по умолчанию — `claude-opus-5`, потоковый ответ, `effort: low` для скорости.
- Если модель отказывается отвечать, запрос автоматически переходит на запасную модель (`fallbacks: "default"`). Если отказалась вся цепочка, пользователь получает безопасный текст с экстренными номерами.
- В системном промпте: не давать советов по ставкам, не поддерживать «отыграться», не советовать кредиты, при кризисе — экстренные номера.
- Сервер дополнительно ищет в сообщении кризисные слова на трёх языках и показывает блок с номерами независимо от ответа модели.
- Лимиты: 5 бесплатных сообщений в день на устройство (`FREE_AI_PER_DAY`), 200 с «Плюсом», плюс ограничения по IP.

Стоимость: по прайсу Anthropic на момент разработки `claude-opus-5` стоит $5 за миллион входных и $25 за миллион выходных токенов. Одно сообщение — примерно 2–3 цента: промпт с историей плюс короткий ответ. `claude-haiku-4-5` примерно в 5 раз дешевле, `claude-sonnet-5` — в 2,5 раза. Модель меняется переменной `AI_MODEL`, но это решение о качестве, поэтому по умолчанию стоит самая сильная. Реальный расход смотрите в консоли Anthropic после первых дней.

## Оплата «Плюса»

Пока нет договора эквайринга, оплата работает вручную:

1. В `.env` укажите номер для перевода и контакт для чека: `PAY_KG_PHONE`, `PAY_KG_CONTACT` (MBank) или `PAY_KZ_PHONE`, `PAY_KZ_CONTACT` (Kaspi).
2. Человек переводит деньги и присылает чек.
3. Вы выпускаете код и отправляете его в ответ:
   ```bash
   npm run codes -- issue --days 30 --note "MBank, чек 26.09"
   ```
4. Человек вводит код в приложении. Код одноразовый и привязывается к одному телефону.

Когда появится ИП и договор с Finik или Freedom Pay (Кыргызстан) либо Kaspi Pay (Казахстан), ручной шаг заменяется вебхуком оплаты. Выпуск кодов и проверка токенов уже готовы.

## Реклама и воронка

Ссылки из рекламы делайте с метками:

```text
https://ваш-домен/?utm_source=tiktok&utm_campaign=truth1#truth
https://ваш-домен/?utm_source=instagram&utm_campaign=sos1
```

- `#truth` открывает калькулятор сразу, без онбординга. Это самый «рекламный» экран: человек вводит свои цифры и видит свой проигрыш за год.
- Приложение запоминает `utm_source` и шлёт на сервер только названия событий:
  `app_open` → `onboarding_start` → `test_done` → `setup_done` → `sos_start` / `checkin` → `premium_view` → `premium_redeemed`.
- Статистика: `npm run codes -- stats --days 30` или `GET /api/admin/stats` с заголовком `Authorization: Bearer <ADMIN_TOKEN>`.

Первые гипотезы для рекламы:

| Креатив | Посыл | Куда ведёт |
|---|---|---|
| «Посчитай свою ставку» | 500 сом × 10 ставок в неделю при марже 5% = в среднем минус 12 тыс. сом за год | `#truth` |
| «Тянет после зарплаты?» | Одна кнопка — 10 минут, и волна проходит | главная, SOS |
| «30 дней без ставок = 40 тыс. на кредит» | Если на ставки уходило ~9 тыс. в неделю, за месяц это 40 тыс. сом | главная |

- **Кому показывать.** Сначала Бишкек и Ош, 18–35 лет, интересы: футбол, UFC, киберспорт. Бюджет на первую неделю — $100–200 на 3–4 креатива.
- **Главная метрика.** Стоимость одного `setup_done` (человек составил план). Смотрите её по каждому `utm_campaign`.
- **Модерация.** Платформы строго модерируют всё, что связано со ставками. В креативах не показывайте коэффициенты, логотипы букмекеров и интерфейс ставок; подавайте тему как здоровье и деньги.
- **Тон.** Без стыда и запугивания: «вернуть контроль», «бесплатно, без регистрации».

- [ ] Шаги NextDNS и «Экранного времени» проверены на свежих Android и iPhone.
- [ ] Список сайтов букмекеров (`public/js/content/blocking.js`) актуален.
- [ ] Условия самоограничения через eGov (Казахстан) сверены с порталом.
- [ ] Заданы `APP_SECRET`, `ADMIN_TOKEN`, платёжные реквизиты; сайт работает по HTTPS.
- [ ] Пользовательское соглашение и политика конфиденциальности (в том числе про передачу сообщений чата в Anthropic).

## Устройство кода

```text
public/               приложение (без сборки: ES-модули + Preact/htm)
  js/logic/           чистая логика с тестами: PGSI, счётчики, математика ставок, аналитика
  js/core/            хранилище, словари, API, маршруты
  js/content/         тексты ru/ky/kk, шаги блокировки, контакты
  js/ui/              компоненты, графики, экраны
  sw.js               офлайн-режим
server/               Node без фреймворков: API, ИИ, коды подписки, статистика (SQLite из node:sqlite)
test/                 node --test и сквозной прогон Playwright
scripts/              иконки, вендоринг Preact
```
