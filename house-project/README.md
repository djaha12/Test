# Двухэтажный жилой дом ≈ 400 м² на участке 6 соток — эскизный проект

Полный пакет предпроектных материалов (стадия ЭП), сгенерированный из **одной параметрической модели** (`src/model.py`):
чертежи (20 листов), расчёты конструкций и инженерных систем, 3D-модель, ведомость объёмов со стоимостью, календарный график, ТЗ и пояснительная записка.

> Не для строительства: требуются инженерно-геологические изыскания, уточнение региона/ТУ и рабочая документация. Все допущения перечислены в `docs/08_Вопросы_заказчику.md`.

## Ключевые показатели

| Показатель | Значение |
|---|---|
| Пятно застройки | 13,0 × 16,0 м = 208 м² |
| Площадь по наружному обмеру (2 этажа) | 416 м² |
| Общая площадь помещений | 340,6 м² (1 эт. 175,1 / 2 эт. 165,6), в т.ч. гараж 23,7 |
| Спален / санузлов | 4 (+ кабинет-гостевая) / 4 |
| Участок | 20 × 30 м; отступы 5,0 м (улица), 3,5 м (бок), 9,0 м (сад) |
| Конструктив | плита 300 мм с рёбрами; газобетон D400 400 мм; монолитные перекрытия 200 мм; стропила 50×200, фальц |
| Тепловая нагрузка | 19,5 кВт (57 Вт/м²); котёл конденсационный 32 кВт; тёплый пол ≈ 2 460 м трубы |
| Ориентировочная стоимость | ≈ 34,5 млн ₽ (≈ 101 тыс. ₽/м² общей площади), ±20 %, МО 2025–2026 |
| Срок строительства | ≈ 59 недель (14 месяцев) |

## Сборка

```bash
cd house-project/src
python3 build.py            # чертежи, расчёты, документы, 3D, PNG, рендеры, сайт
python3 build.py --no-render   # без Playwright
```

Зависимости: Python 3.11 (стандартная библиотека), Node 22 + Playwright с Chromium (для PNG/рендеров), three.js r147 (в `3d/`).

## Как изменить проект

Почти всё описано данными в `src/model.py`: размеры участка и посадка дома (`SITE`), габариты и оси (`EXT_OUTER`, `AXES_*`), стены (`WALLS`), помещения (`ROOMS`), окна и двери (`WINDOWS`, `EXT_DOORS`, `INT_DOORS`), лестница (`STAIR`), кровля (`ROOF`), уровни (`LEVELS`), климат и грунты (`CLIMATE`). После правки — `python3 build.py`: площади, спецификации, нагрузки, расчёты, чертежи, 3D и смета пересчитываются автоматически.
