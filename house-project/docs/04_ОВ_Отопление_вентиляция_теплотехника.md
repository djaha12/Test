## 1. Климатические параметры (СП 131.13330.2020)

- Район: Московская область (принято по умолчанию — уточнить!)
- Расчётная температура наружного воздуха t_н = -25 °С; средняя за отопительный период t_оп = -2.2 °С, продолжительность z_оп = 205 сут.

## 3. Теплопотери и тепловая нагрузка

- Трансмиссионные: Q_тр = Σ(A·n/R)·(t_в − t_н)·1,05 = 246,5·45·1,05 = **11,6 кВт**.
- Вентиляционные (естественная вентиляция, n = 0.5 ч⁻¹, V_вн = 1022 м³): Q_в = 0,34·n·V·Δt = **7,8 кВт**; с рекуператором (η = 75 %): 2,0 кВт.
- **Расчётная тепловая нагрузка отопления: 19,5 кВт** (с ПВУ — 13,6 кВт), т.е. ≈ 57 Вт/м².
- ГВС: бойлер косвенного нагрева 200 л, мощность змеевика 25 кВт (режим приоритета ГВС).
- **Котёл: настенный конденсационный 32 кВт** (модуляция 4–32 кВт), одноконтурный, закрытая камера сгорания; резерв — электрокотёл 9 кВт (опция) или ТЭН бойлера 3 кВт.
- Годовое потребление тепла (оценка): Q_год ≈ 34423 кВт·ч (101 кВт·ч/м²·год с учётом бытовых теплопоступлений); газ ≈ **4152 м³/год** с ГВС.
