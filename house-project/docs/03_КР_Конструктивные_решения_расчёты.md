# Раздел КР — Конструктивные решения. Расчёты (стадия ЭП)

> Расчёты выполнены по упрощённым инженерным методикам в объёме эскизного проекта. Перед рабочим проектированием требуются инженерно-геологические изыскания, уточнение климатического района и поверочный расчёт в ПК (Лира-САПР / SCAD).

## 1. Исходные данные

- Район строительства: Московская область (принято по умолчанию — уточнить!)
- Снеговой район III: S_g = 1.5 кПа (СП 20.13330.2016, табл. 10.1); ветровой район I: w₀ = 0.23 кПа
- Грунт (ПРИНЯТО): суглинок полутвёрдый, R0 = 200 кПа (ПРИНЯТО; требуются изыскания); УГВ ≈ 2.5 м; нормативная глубина промерзания 1.4 м
- Сейсмичность: 5 баллов (при ≥ 7 баллов конструктивная схема меняется: антисейсмические пояса, армирование кладки, каркас)
- Материалы: бетон B25 W6 F150 (R_b = 14,5 МПа), арматура A500C (R_s = 435 МПа); газобетон D400 B2.5 (стены наружные), D500 B3.5 (внутренняя несущая); древесина С24 (2 сорт), R_и = 13 МПа

## 3. Фундаментная плита (СП 22.13330.2016, СП 63.13330.2018)

- Расчётное сопротивление грунта R₀ = 200 кПа (принято для суглинка полутвёрдого, e ≈ 0,8). Условие p ≤ R: 31,9 ≤ 200 кПа — **выполняется**, использование 16 %.
- Дополнительное давление p_доп = p − σ_zg = 31,9 − 11,7 = 20,2 кПа. Осадка (упрощённо, E = 15 МПа): s ≈ (1−ν²)·p·b·ω/E = **15 мм** ≤ s_u = 100 мм (СП 22, прил. Г).
- Изгиб плиты как обратного неразрезного перекрытия под нагрузкой от стен q = 22,2 кПа, пролёт L = 6,27 м (верхняя оценка при равномерном отпоре; по Винклеру моменты ниже на 30–40 %):
  - под стенами (растянут низ): M = qL²/10 = **87,5 кН·м/м** → A_s,треб = 875 мм²/м;
  - в пролёте (растянут верх): M = qL²/14 = **62,5 кН·м/м** → A_s,треб = 615 мм²/м;
  - принято: сетки верх и низ Ø14 A500C шаг 200 в обоих направлениях (A_s = 770 мм²/м, M_u = 77,5 кН·м/м); под осью 2 — дополнительные нижние стержни Ø14 ш. 200 в полосе 2,0 м (M_u = 147,3 кН·м/м). Защитный слой 50 мм (низ), 35 мм (верх).
- Срез под осью 2: погонная нагрузка N = 171 кН/м, Q = 85 кН/м на сторону ≤ Q_b,min = 0,5·R_bt·b·h₀ = 289 кН/м (с ребром 300 мм) — **выполняется**.
- Объём бетона плиты с рёбрами ≈ 75,6 м³, арматура ≈ 7,0 т (≈ 93 кг/м³).
- Конструкция: подушка ПГС 400 мм (уплотнение до K=0,95, послойно), геотекстиль, ЭППС 100 мм (прочность ≥ 250 кПа), полиэтилен 200 мкм, плита 300 мм B25 W6 F150, рёбра-ростверк 400×300 (4Ø12 + хомуты Ø8 ш. 300); утеплённая отмостка 1,0 м с ЭППС 50; дренаж пристенный Ø110 в геотекстиле с колодцами по углам.

- Реакции: промежуточный прогон 10,1 кН/м, коньковый 6,3 кН/м, наружная стена 4,5 кН/м.
