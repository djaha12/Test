# Дополнительные расчёты (стадия ЭП)

## 1. Звукоизоляция (СП 51.13330.2011, СП 275.1325800.2016)

Для помещений одного дома нормативных требований нет; принят комфортный уровень для стен между спальнями и смежными помещениями R_w ≥ 43 дБ (как между комнатами квартиры и кухней по СП 51, табл. 2).

|---|---|---|---|
| Перегородка D500 100 мм + штукатурка 2×10 | 80 | 40 | кладовые, санузлы, гардеробные |
| Перегородка D500 150 мм + штукатурка 2×10 | 105 | 45 | спальни, кабинет — принято |

| Наружная стена D400 400 мм | 198 | 53 | уличный шум (норма для жилых ≥ 30–35 дБ по окнам) |
| Окно 2-камерный стеклопакет 4i-14-4-14-4i | — | 34 | класс В по ГОСТ 23166 |

Междуэтажное перекрытие: плита 200 мм (m = 500 кг/м²), R_w ≈ 55 дБ ≥ 52 дБ; ударный шум: L_nw,0 ≈ 78 дБ, плавающая стяжка 70 мм по ПСБ-С 20 мм даёт ΔL_w ≈ 24 дБ → **L_nw ≈ 54 дБ ≤ 60 дБ** — выполняется. Обязательна демпферная лента по периметру стяжки и отсутствие звуковых мостиков (трубы в гильзах).

**Вывод:** перегородки, ограждающие спальни и кабинет, приняты 150 мм (R_w ≈ 45 дБ); при желании R_w ≥ 50 дБ — 100 мм газобетона + облицовка ГКЛ 2×12,5 на независимом каркасе с минватой 50 мм.

## 5. Дополнительные проверки конструкций

**Прогиб балки Б-1 (250×700, пролёт 3,60 м):** q_n = 123,6 кН/м, I = 71.46·10⁻⁴ м⁴, EI_eff = 0,35·E_b·I (трещины + ползучесть) → f = 5qL⁴/(384EI) = **3,6 мм** ≤ L/250 = 14,4 мм и ≤ L/500 = 7,2 мм (кладка над балкой) — выполняется.

**Фронтон на ветер:** газобетон D500 300 мм, высота 3,87 м, расчётный напор w = 0,266 кПа (w₀ = 0.23, k = 0,75, c = 0,8 + 0,3, γ_f = 1,4); M = wh²/8 = 0,50 кН·м/м, σ_изг = 33 кПа минус обжатие от собственного веса 10 кПа ≤ R_tb = 90 кПа (растяжение при изгибе кладки на клею) — выполняется; фронтон дополнительно крепится к прогонам и стропилам (уголки ш. 1,5 м), армируется каждый 3-й ряд.

**Тяга естественной вентиляции** (Δp = h·g·(ρ_н − ρ_в) при t_в = 20 °С; потери — решётка, канал, дефлектор, ζ_Σ ≈ 4,5):

При +15 °С и летом тяга отсутствует — предусмотрены осевые вентиляторы в санузлах (с таймером) и кухонный зонт; для круглогодичного воздухообмена рекомендуется ПВУ с рекуперацией.
